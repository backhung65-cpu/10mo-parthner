# 동화 템플릿 이미지 사양서 및 거대 제작 워크플로우

## 1. 동화 내지 템플릿 이미지 사양서

### A. 핵심 디자인 정체성

#### 스타일
- 손으로 그린 아날로그 그림책
- 색연필 + 수채화 + 종이·천 콜라주 질감
- 완벽하게 매끈한 디지털 일러스트보다 약간 거친 손맛 유지
- 따뜻하고 부드러운 저채도 색상
- 어린이의 감정을 과장하지 않고 표정과 자세로 전달

#### 핵심 특징
- 그림이 페이지 전체를 채우지 않음
- **흰 여백이 이야기의 일부**
- 장면마다 캐릭터 크기와 위치가 크게 변함
- 같은 인물이 반복되더라도 구도가 계속 달라짐
- 배경 묘사를 최소화하고 필요한 사물만 배치
- 텍스트와 그림이 경쟁하지 않도록 분리

## 2. 페이지 구성 규칙

### 기본 페이지 타입

#### TYPE A — 공간형 장면
인물 + 실내·실외 공간을 함께 보여주는 장면.

```text
┌─────────────────────────┐
│ 그림 60~75%             │
│                         │
│        캐릭터            │
│                         │
│                 텍스트   │
│                 영역     │
└─────────────────────────┘
```

**용도**
- 사건 발생
- 장소 소개
- 가족·친구 관계
- 행동 장면

#### TYPE B — 여백 중심 감정 장면

```text
┌─────────────────────────┐
│                    문장 │
│                         │
│                         │
│        작은 캐릭터       │
│                         │
│      넓은 흰 여백        │
└─────────────────────────┘
```

**용도**
- 외로움
- 걱정
- 생각
- 기다림
- 감정 전환

#### TYPE C — 관계 중심 장면

```text
┌─────────────────────────┐
│                         │
│       A       B         │
│       → 시선 ←          │
│                         │
│                         │
│ 텍스트                  │
└─────────────────────────┘
```

캐릭터 두 사람의 거리와 시선으로 관계를 표현합니다.

#### TYPE D — 클로즈업 감정 장면
캐릭터를 크게 배치하여 다음 감정을 보여줍니다.
- 포옹
- 위로
- 기쁨
- 화해
- 두려움

배경은 거의 제거합니다.

#### TYPE E — 상징 장면
감정을 실제 사물처럼 표현합니다.

예:
- 걱정 → 머리 위 먹구름
- 기쁨 → 햇살
- 혼란 → 뒤엉킨 선
- 사랑 → 따뜻한 빛
- 용기 → 작은 빛 또는 열린 길

이 방식은 어린이에게 추상적 감정을 직관적으로 전달하기 좋습니다.

## 4. 동화 이미지 공통 스타일 프롬프트 규격

```text
어린이 그림책용 손그림 일러스트.

부드러운 수채화, 색연필, 종이와 패브릭 콜라주가 혼합된
따뜻한 아날로그 그림책 스타일.

표면에는 종이 섬유, 연필선, 천 질감과
미세하게 불규칙한 손그림 흔적이 남아 있다.

부드러운 저채도 색상.
과도하게 선명한 디지털 색상 금지.

넓은 흰 여백을 적극적으로 활용한다.
배경은 필요한 사물만 최소한으로 표현한다.

캐릭터의 감정은 얼굴뿐 아니라
몸의 자세, 손동작, 거리, 시선으로 표현한다.

페이지마다 영화적인 화면보다는
고전적인 그림책 편집 구성을 사용한다.

3D CGI 금지.
애니메이션 영화 스타일 금지.
과도한 디테일 금지.
사진풍 금지.
광택 효과 금지.
복잡한 배경 금지.
```

## 5. 가장 중요한 페이지 설계 규칙

각 페이지를 생성하기 전에 반드시 다음 6개를 정의합니다.

```text
1. 이 페이지에서 일어나는 사건
2. 가장 중요한 감정
3. 독자의 시선이 처음 닿을 위치
4. 캐릭터 위치
5. 캐릭터 시선 방향
6. 텍스트 여백
```

### 예시: Page Bible

```text
PAGE 12

사건:
아이가 엄마에게 고민을 이야기한다.

감정:
불안 → 안심

주요 캐릭터:
아이 / 엄마

아이 위치:
왼쪽 하단

엄마 위치:
오른쪽 중앙

시선:
아이 → 엄마
엄마 → 아이

핵심 행동:
엄마가 아이의 손을 잡는다.

여백:
상단 오른쪽 35%

텍스트:
2~3문장

페이지 역할:
감정적 전환점
```

이 정보를 **Page Bible**로 저장합니다.

## 6. 거대 동화 제작 워크플로우

추천 구조는 다음과 같은 **12단계**입니다.

```text

 ↓
스토리 철학
 ↓
스토리라인
 ↓
페이지 설계
 ↓
캐릭터 설계
 ↓
비주얼 설계
 ↓
전체 스토리보드
 ↓

 ↓
텍스트 편집
 ↓
표지·간지·후지
 ↓
품질검수
 ↓
출판·등록
```

## PHASE 2. Story Bible 구축

추천 기본 구조:

```text

9. 새로운 이해
10. 작은 행동
11. 변화
12. 새로운 일상
```

여기서 책 전체의 메시지를 확정합니다.

## PHASE 6. 전체 동화 Storyboard 생성

바로 페이지를 개별 생성하지 않고,
먼저 **전체 페이지를 하나의 이미지에 작은 스케치로 생성**합니다.

예:

```text
┌──┬──┬──┬──┐
│01│02│03│04│
├──┼──┼──┼──┤
│05│06│07│08│
├──┼──┼──┼──┤
│09│10│11│12│
└──┴──┴──┴──┘
```

이 단계에서 검토할 항목:
- 캐릭터 위치
- 캐릭터 크기
- 화면 반복
- 좌우 흐름
- 클로즈업 반복
- 여백
- 감정 강도
- 페이지 리듬

### 페이지 리듬 예시

```text

↓

↓

↓

↓

```

```text

```

```text

   page_02_clean

   page_03_clean
   page_03_text
```

## PHASE 10. 간지·면지

면지는 단순 장식이 아니라 이야기의 일부로 활용합니다.

예:
- 앞면지: 작은 먹구름
- 뒷면지: 먹구름 사이로 햇살

이렇게 하면 책 자체가 하나의 이야기 구조를 갖습니다.

## 8. 핵심 원칙

**“페이지를 하나씩 잘 만드는 것”보다 “책 전체의 시각적 흐름을 먼저 설계하는 것”이 우선입니다.**

따라서 핵심 순서는 반드시 다음과 같습니다.

```text
Story Bible → Character Bible → Page Bible → Visual Bible → 전체 Storyboard → 개별 생성
```

이 구조라면 최종적으로는 사용자가

> “주제: 친구와 싸운 뒤 먼저 사과하는 용기에 대한 24페이지 어린이 동화”

정도만 입력해도,
**스토리 → 페이지 → 캐릭터 → 전체 스케치 → 개별 삽화 → 표지 → 출판 데이터까지 진행하는 ‘동화 제작 OS’** 형태로 구축할 수 있습니다.
